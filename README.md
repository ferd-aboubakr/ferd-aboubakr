## 💼 Freelance — work with me

I take on dev projects for clients alongside my studies. Typical engagements:

- **Full-stack web apps** — React, or server-rendered Express + EJS, on the front; Node/Express or Laravel on the back
- **REST APIs** — auth and roles (JWT / Sanctum), MongoDB or MySQL, documented endpoints, tests where it counts
- **Admin dashboards & internal tools** — CRUD, filtering, reporting views
- **Figma → code** — responsive, accessible pages
- **Embedded prototypes** — Arduino / C++ sensor and control work

I work from a brief or a rough idea: we scope it, I build in milestones with something reviewable at each step, and you get the repo plus setup docs at the end.

**Availability:** open to new freelance projects — remote, or on-site around Nador / Morocco. Email is the fastest way to reach me.
